# نسخه‌ی اندروید (Kivy)

همان موتور نسخه‌ی ویندوز (استیکر ثابت PNG و متحرک TGS، تقویم شمسی/میلادی، فونت، کشیدگی) داخل یک برنامه‌ی اندروید.
**توجه:** این کد در محیط توسعه فقط در بخش «هسته» (`src/mobile/core.py`) تست خودکار شده است؛ رابط Kivy و ساخت APK
هنوز روی گوشی/سرور واقعی اجرا نشده‌اند. اولین ساخت ممکن است نیاز به رفع خطای کوچک داشته باشد.

## ساخت APK (بدون نصب چیزی روی کامپیوتر): GitHub Actions
1. یک ریپوی خصوصی در GitHub بسازید و کل پوشه‌ی پروژه را در آن بگذارید (شاخه‌ی `main`).
2. تب **Actions** ← «Build Android APK» ← **Run workflow**. حدود ۲۰–۴۰ دقیقه (بار اول) طول می‌کشد.
3. در پایان از بخش **Artifacts** فایل `TelegramDateStudio-apk` را دانلود و روی گوشی نصب کنید (نصب از منبع ناشناس را مجاز کنید).

## ساخت دستی (لینوکس/WSL)
```
pip install buildozer cython
python android/prepare.py
cd android && buildozer android debug
```
خروجی: `android/bin/*.apk`

## استفاده
1. «انتخاب قالب»: فایل `.png` یا `.tgs` استیکر نمونه (تاریخ و نواحی خودکار تشخیص داده می‌شود).
2. ماه/سال، فونت، اندازه و کشیدگی را تنظیم کنید؛ پیش‌نمایش روز اول ماه بلافاصله به‌روز می‌شود.
3. «ساخت استیکرهای این ماه»: فایل‌ها و ZIP در **Downloads/TelegramDateStudio** ذخیره می‌شوند؛ «اشتراک‌گذاری ZIP» منوی اشتراک اندروید را باز می‌کند.
4. فونت دلخواه: فایل `.ttf` را در حافظه‌ی گوشی داخل `TelegramDateStudio/fonts` بگذارید و برنامه را دوباره باز کنید. (فونت پیش‌فرض DejaVu است؛ برای ظاهر بهتر یک فونت فارسی مثل وزیر/ساهل بگذارید.)

## محدودیت‌های نسخه‌ی اول
- تنظیم اندازه/جابه‌جایی فقط به‌صورت یک اندازه‌ی کلی است (نه برای هر متن جدا)؛ صفحه‌ی اصلاح دستیِ نواحی PNG نیست.
- انتخابگر فایل اندروید (plyer) روی بعضی گوشی‌ها برای فایل‌های داخل Downloads مسیر قابل‌خواندن برنمی‌گرداند؛ در این حالت فایل را به حافظه‌ی داخلی (مثلاً پوشه‌ی Documents) منتقل کنید.
- ذخیره در Downloads از MediaStore استفاده می‌کند (اندروید ۱۰ به بالا)؛ در اندروید ۹ و پایین‌تر مستقیم در پوشه‌ی Downloads کپی می‌شود.
- پیش‌نمایش TGS با رندر تقریبی Pillow است (مثل نسخه‌ی ویندوز بدون rlottie).

## به‌روزرسانی: دسترسی فایل و ظاهر جدید
- خطای «permission denied»: در اندروید ۱۱ به بالا برنامه اجازه‌ی خواندن مسیر `/storage/emulated/0/...` را ندارد. حالا فایل با **انتخابگر سیستم اندروید (SAF)** انتخاب و در حافظه‌ی خودِ برنامه کپی می‌شود؛ نیازی به هیچ مجوزی نیست.
- ظاهر برنامه مثل نسخه‌ی ویندوز است: چهار کاشی (قالب، فونت‌ها، ماه و سال، اندازه‌ها)، صفحه‌های درون‌پنجره‌ای با «بازگشت/تأیید»، تم روشن/شب، فهرست فونت با نمونه‌ی متن، اندازه/جابه‌جایی/کشیدگی برای هر متن، و صفحه‌ی تعیین نواحی استیکر ثابت.
- اگر ارور دیگری دیدید، برنامه متن خطا را روی صفحه نشان می‌دهد؛ همان را بفرستید.
- برای فونت فارسی رابط (مثل B Yekan) فایل ttf را در `assets/ui_fonts` بگذارید.
