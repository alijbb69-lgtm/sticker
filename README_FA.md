# Telegram Date Studio

ساخت خودکار استیکرهای متحرک تاریخ (`.tgs`) یک ماه کامل از روی یک قالب استیکر تاریخ که نوشته‌هایش Outline شده‌اند.

## نصب و اجرا (ویندوز)
```
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## استفاده
1. فایل قالب `.tgs` را انتخاب کنید. برنامه خودش لایه‌های تاریخ و حتی «تاریخی که در قالب نوشته شده» را تشخیص می‌دهد.
2. دو فونت انتخاب کنید: فونت فارسی (برای تاریخ شمسی و روز هفته فارسی) و فونت انگلیسی (برای تاریخ میلادی و روز هفته انگلیسی). اگر فونت حرف یا رقمی را نداشته باشد، زیر همان کادر هشدار می‌دهد.
3. ماه و سال شمسی را انتخاب کنید (پیش‌نمایش روز اول همان ماه نشان داده می‌شود).
4. «ساخت استیکرهای این ماه» و انتخاب پوشه. خروجی: `1405-08-01.tgs` تا آخر ماه، یک ZIP و `report.txt`.

اگر قالب نوشته‌ی تاریخ نداشته باشد (مثلاً قالب خالی با کادر بی‌متن)، برنامه آن را رد می‌کند و پیام می‌دهد؛ چیزی خراب نمی‌شود.

بدون رابط گرافیکی: `python tools/cli.py قالب.tgs --year 1405 --month 8 --out خروجی [--fa-font f.ttf --en-font f.ttf]`

## چه چیزی عوض می‌شود
فقط مسیرهای حروف هر متن (روز و سال و ماه شمسی/میلادی، روز هفته فارسی/انگلیسی). Fill، Transform، کی‌فریم‌ها، parent، ترتیب لایه‌ها، لوگو و بقیه‌ی عناصر همان می‌ماند. حروف با fontTools از فونت به Bézier تبدیل می‌شوند، با اتصال حروف فارسی، نیم‌فاصله، RTL/LTR و ارقام فارسی/لاتین.

## اعتبارسنجی هر فایل
GZIP، JSON، ساختار Lottie، بوم ۵۱۲×۵۱۲، ۳۰–۶۰ fps، حداکثر ۳ ثانیه، حداکثر ۶۴KB، نبود Text Layer/Image/Expression، وجود متن‌های جایگزین‌شده، رندر آزمایشی. فایل نامعتبر در `_rejected` می‌رود و موفق حساب نمی‌شود.

## محدودیت‌ها
- روی دو قالب آزمایش شده است: قالب «صرافی اکسین» و یک قالب آزمایشی داخلی. قالب‌های دیگر با ساختار متفاوت ممکن است تشخیص داده نشوند (در این صورت پیام می‌دهد).
- فونت اصلی قالب ناشناخته است؛ با فونت همراه (DejaVu) شکل حروف با قالب کمی فرق دارد. فونت دلخواه را انتخاب کنید.
- قالب شما `Merge Paths` دارد و همان‌طور حفظ می‌شود (هشدار در گزارش).
- آزمون با rlottie (رندرر تلگرام) انجام نشده (در محیط ساخت نصب نبود)؛ رندر آزمایشی با Pillow است.
- اجرای رابط PySide6 در محیط ساخت ممکن نبود؛ منطق آن با PySide6 ساختگی آزموده شد.

## تست
`python -m unittest discover -s tests -v`

## قالب‌های طلایی / سایه‌دار
اگر قالب هر متن را چندبار (سایه، کانتور، گرادیان) تکرار کرده باشد، برنامه کپی‌ها را خودکار پیدا می‌کند و همه را همزمان عوض می‌کند.
برای پیش‌نمایش دقیق رنگ‌ها (گرادیان، ماسک، مت) بسته‌ی `rlottie-python` را نصب کنید (در requirements.txt هست)؛ در غیر این صورت پیش‌نمایش تقریبی است و فقط ظاهر پیش‌نمایش با استیکر واقعی فرق می‌کند، نه فایل خروجی.

## اندازه‌ی نوشته‌ها
بعد از انتخاب قالب، کارت «اندازه‌ی نوشته‌ها» ظاهر می‌شود: برای هر متن (روز، ماه، سال، روز هفته) درصد اندازه را (۳۰ تا ۳۰۰٪) تغییر دهید؛ پیش‌نمایش و همه‌ی استیکرهای ماه با همان اندازه ساخته می‌شوند. کپی‌های سایه/خط‌دور هم با همان ضریب تغییر می‌کنند.

## رابط کاربری (نسخه‌ی جدید)
صفحه‌ی اصلی چهار کاشی دارد: **قالب، فونت‌ها، ماه و سال، اندازه‌ها**. روی هر کدام بزنید تا پنجره‌ی همان بخش باز شود؛ سپس «ساخت استیکرهای این ماه».
- **فونت‌ها:** فهرست نمونه‌دار (هر فونت با متن نمونه‌ی خودش)، دو زبانه‌ی شمسی/میلادی، جستجو و افزودن فایل فونت.
- **تم:** دکمه‌ی بالا-چپ بین نیومورفیسم روشن و شب جابه‌جا می‌کند (انتخاب شما ذخیره می‌شود).
- روز هفته اگر در قالب نباشد (یا فقط یک زبانش باشد) چیزی اضافه نمی‌شود؛ کلمه‌های کشیده مثل «شـنـبـه» هم تشخیص داده می‌شوند.

## rlottie-python (اختیاری، برای پیش‌نمایش دقیق)
rlottie همان موتور رندر Lottie است که تلگرام استفاده می‌کند. با نصب `rlottie-python` پیش‌نمایش برنامه دقیقاً مثل تلگرام کشیده می‌شود (گرادیان، ماسک، مت) و اعتبارسنجی هم یک آزمون رندر واقعی اضافه می‌کند.
نصب (داخل همان .venv): `.\.venv\Scripts\python.exe -m pip install rlottie-python` — یا `pip install -r requirements.txt`.
بدون آن برنامه کاملاً کار می‌کند؛ فقط پیش‌نمایش تقریبی است و فایل‌های خروجی هیچ تفاوتی ندارند.

## ذخیره‌ی خودکار تنظیمات
آخرین قالب، فونت‌ها (از جمله فونت جداگانه‌ی هر متن)، ماه و سال، اندازه‌ها، جابه‌جایی‌ها و پوشه‌ی خروجی ذخیره می‌شوند و دفعه‌ی بعد خودکار برمی‌گردند.
در صفحه‌ی «اندازه‌ها» زبانه‌ی «جابه‌جایی» برای هر متن جابه‌جایی افقی/عمودی (پیکسل) دارد؛ در صفحه‌ی «فونت‌ها» زبانه‌ی «هر متن جدا» فونت اختصاصی هر متن را می‌دهد. حجم استیکر پیش‌نمایش (و حد ۶۴ کیلوبایت) زیر پیش‌نمایش نوشته می‌شود.

## استیکر ثابت (PNG)

طبق [مستندات تلگرام](https://core.telegram.org/import-stickers): استیکر ثابت PNG یا WebP است، یک ضلع دقیقاً ۵۱۲ و ضلع دیگر ≤ ۵۱۲، حجم ≤ ۵۱۲ کیلوبایت، و زمینه‌ی شفاف توصیه می‌شود.

- فایل `.png` را مثل `.tgs` در صفحه‌ی «قالب» انتخاب کنید؛ **همه‌چیز خودکار است**: ناحیه‌ی هر نوشته، سبک ارقام (فارسی/لاتین) و حتی تاریخِ نوشته‌شده روی استیکر (با تطبیق شکل و هم‌خوانی تقویم شمسی↔میلادی↔روز هفته) تشخیص داده می‌شود.
- نوشته‌ی قدیمی با بازسازی زمینه از چهار لبه‌ی اطرافش پاک می‌شود (تکه‌ی کونز: دقیق برای زمینه‌ی تخت/گرادیانی، بدون تاری) و نوشته‌ی جدید با فونت انتخابی، هم‌اندازه و هم‌رنگ کشیده می‌شود. زمینه‌ی تمیز فقط یک‌بار ساخته می‌شود؛ ساخت هر روز ≈ ۱۰ میلی‌ثانیه.
- فقط اگر تشخیص خودکار اشتباه بود، «تعیین نوشته‌ها روی استیکر ثابت» را باز کنید و تاریخ/ناحیه را اصلاح کنید.
- فونت، اندازه و جابه‌جایی مثل استیکر متحرک کار می‌کند.
- محدودیت‌ها: رنگ متن تک‌رنگ است (گرادیان/سایه‌ی خودِ متن بازسازی نمی‌شود)؛ پاک‌کردن روی زمینه‌ی پرجزئیات (عکس) ضعیف‌تر است.
- خط فرمان: `python tools/cli.py t.png --year 1405 --month 8 --out out` (تاریخ نوشته‌شده خودکار تشخیص داده می‌شود؛ `--written 1405-08-01` و `--assign` فقط برای اصلاح دستی).
- توجه: رابط گرافیکی PNG روی PySide6 واقعی اجرا نشده؛ موتور با آزمون خودکار تست شده است.

## کشیدگی حروف (شـنـبـه)
اگر نوشته‌ی روز هفته یا نام ماه در قالب کشیده است («جـمـعـه»، «آبـــان»)، میزان کشیدگی از روی نسبت پهنا/ارتفاع نوشته‌ی قالب خودکار حدس زده می‌شود و برای همه‌ی روزها/ماه‌ها یکسان اعمال می‌شود: شـنـبـه، یـکـشـنـبـه، دوشـنـبـه، سـه‌شـنـبـه، چهارشـنـبـه، پـنـجـشـنـبـه، جـمـعـه. اگر برای کلمه‌ای بلندتر جا نبود، کشیدگی تا ۱ کم می‌شود و سپس کل متن کمی کوچک می‌شود. برای تغییر دستی: «اندازه‌ها» ← تب «کشیدگی» (۰ = ساده). برای PNG و TGS هر دو کار می‌کند.
